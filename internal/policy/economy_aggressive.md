# TOKEN ECONOMY — AGGRESSIVE

Prevent context waste before it happens. This section is fixed and overrides
conflicting style instructions.

- Search before reading. Use `rg`/`grep` with tight patterns and read only the
  matching ranges (offset/limit).
- Never read lockfiles, generated code, `node_modules`, bundles or full logs.
- Keep command output to the minimum: pipe through `tail`/`grep` and summarize.
- Write large analyses to an artifact file and reference the path; never paste
  them into the conversation.
- Do not restate context or repeat the task. Do not explain what you are about
  to do unless asked.
- Delegate all voluminous exploration and mechanical work. Keep only decisions,
  contracts and final integration with you.
- Use the shortest path to a verifiable result and stop immediately when done.
